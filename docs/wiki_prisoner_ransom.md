# Выкуп за военнопленных

> travnik: сумма выкупа, которую платят военнопленные при успешном допросе,
> зависит от типа пленного и текущего прогресса игры.

---

## Назначение

Военнопленные появляются только при включённой системе плена
(`ALLOW_TAKE_PRISONERS`). В тюрьме их можно допрашивать на задании
**«Допрос военнопленных»** (`FAC_INTERROGATE_PRISONERS`).

После накопления достаточного количества очков допроса для каждого пленного
случайным образом определяется результат:

1. пленный переходит на нашу сторону и становится ополченцем;
2. пленный выдаёт сведения о передвижении врага;
3. пленный платит выкуп;
4. пленного отпускают без выгоды.

Раньше сумма выкупа была одинаковой для всех типов пленных
(`(Random(5) + 1) * 100`, то есть 100–500 $). Теперь она рассчитывается
по типу пленного и текущему прогрессу кампании.

---

## Формула

```
выкуп = round( БАЗА[тип] * (1 + K * P / 100) )
```

где:

| Обозначение | Значение |
|-------------|----------|
| `БАЗА[тип]` | базовая сумма для типа пленного из `Ja2_Options.ini` |
| `K` | `PRISONER_RANSOM_PROGRESS_COEFFICIENT` |
| `P` | текущий прогресс игры в процентах (`CurrentPlayerProgressPercentage()`, 0–100) |

Сумма округляется до целого числа. Итоговая сумма не может быть меньше
базовой, если коэффициент неотрицательный.

### Смысл коэффициента прогресса

* `K = 0.0` — выкуп всегда равен базовой сумме, прогресс не влияет;
* `K = 0.5` — к 100 % прогресса выкуп увеличивается в 1.5 раза;
* `K = 1.0` — к 100 % прогресса выкуп удваивается (значение по умолчанию);
* `K = 2.0` — к 100 % прогресса выкуп утраивается.

Прогресс берётся **текущий**, а не максимальный за кампанию. Если игрок теряет
сектора и прогресс падает, выкуп также снижается.

### Примеры при значениях по умолчанию

| Тип пленного | База, $ | 0 % | 25 % | 50 % | 75 % | 100 % |
|--------------|--------:|----:|-----:|-----:|-----:|------:|
| Администратор | 100 | 100 | 125 | 150 | 175 | 200 |
| Регуляр | 200 | 200 | 250 | 300 | 350 | 400 |
| Элита | 300 | 300 | 375 | 450 | 525 | 600 |
| Офицер | 500 | 500 | 625 | 750 | 875 | 1000 |

## Настройки

Параметры читаются из `Ja2_Options.ini`, секция
`[Strategic Gameplay Settings]`.

```ini
[Strategic Gameplay Settings]

; Базовая сумма выкупа за администратора
PRISONER_RANSOM_MONEY_ADMIN = 100

; Базовая сумма выкупа за регулярного солдата
PRISONER_RANSOM_MONEY_REGULAR = 200

; Базовая сумма выкупа за элитного солдата
PRISONER_RANSOM_MONEY_ELITE = 300

; Базовая сумма выкупа за офицера
PRISONER_RANSOM_MONEY_OFFICER = 500

; Прирост выкупа за каждые 100% прогресса игры
; 1.0 = к концу кампании выкуп удваивается
PRISONER_RANSOM_PROGRESS_COEFFICIENT = 1.0
```

| Параметр | По умолчанию | Диапазон | Назначение |
|----------|:---:|:---:|-----------|
| `PRISONER_RANSOM_MONEY_ADMIN` | `100` | 0–1 000 000 | выкуп за администратора |
| `PRISONER_RANSOM_MONEY_REGULAR` | `200` | 0–1 000 000 | выкуп за регулярного солдата |
| `PRISONER_RANSOM_MONEY_ELITE` | `300` | 0–1 000 000 | выкуп за элитного солдата |
| `PRISONER_RANSOM_MONEY_OFFICER` | `500` | 0–1 000 000 | выкуп за офицера |
| `PRISONER_RANSOM_PROGRESS_COEFFICIENT` | `1.0` | 0.0–10.0 | множитель прироста выкупа от прогресса игры |

Если параметр отсутствует в INI-файле, используется значение по умолчанию.
Комментарии в INI-файле должны располагаться на отдельной строке перед
параметром.

---

## Как определяется тип пленного

Пленные допрашиваются в фиксированном порядке:

1. администраторы (`PRISONER_ADMIN`);
2. регулярные солдаты (`PRISONER_REGULAR`);
3. элита (`PRISONER_ELITE`);
4. офицеры (`PRISONER_OFFICER`).

При обработке результатов для каждого пленного по счётчикам уже допрошенных
определяется его тип. Поэтому выкуп начисляется именно за того пленного,
которого обрабатывает текущая итерация.

---

## Где начисляется выкуп

В `HandlePrisonerProcessingInSector()` (`Strategic\Assignments.cpp`) ветка
выкупа вызывает:

```cpp
ransommoney += CPrisonerRansom::GetRansomMoneyByProcessedIndex( i, interrogatedprisoners );
```

После обработки всей группы:

* общая сумма записывается в финансовую книгу как
  `PRISONER_RANSOM` — «Выкуп за освобожденных заключенных»;
* игроку показывается сообщение `%d prisoners paid ransom money.`
  с количеством пленных, заплативших выкуп.

В сообщении отображается только количество пленных, а не сумма: итоговая
сумма видна в финансовой книге.

## Особенности

* Сумма выкупа теперь детерминирована для каждого типа пленного и прогресса:
  случайный разброс `100–500 $` больше не используется.
* Изменение настроек не требует новой игры: параметры читаются при запуске
  из `Ja2_Options.ini`.
* Новые поля не добавляются в структуры сохранений, поэтому совместимость
  сейвов не нарушается.
* Если в счётчиках допрошенных пленных нет данных, тип по умолчанию
  определяется как администратор.
